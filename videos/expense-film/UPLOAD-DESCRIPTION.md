Proofline — Beyond the happy path | Neural Storm FT-05

An expense app looks finished. Under an adversarial search, one user's data crosses into another user's results. An async save loop can also report completion before writes finish. Proofline reviews the code, provides source context and model assessments, generates repairs, and checks those repairs against protected contracts.

This edited animated demonstration uses an authored scenario and actual recorded review, model patches and local Python/SQLite + Node contract execution. App cards are explanatory graphics, not a recording of a deployed application. The graph distinguishes import relationships from source-assessed dynamic calls; it does not claim complete static taint tracking. No general accuracy or real customer incident claim is made.
